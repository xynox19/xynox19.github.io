# Portfolio Image Placeholders

Keep draft and replacement imagery for the portfolio in this folder.

- `portrait-placeholder.svg` is a temporary portrait visual. Replace it with your portrait image when ready.
- `project-placeholder.svg` is a reusable temporary project-cover visual. Keep project screenshots here with descriptive names, then set the matching `image` path on a project in `script.js`.

The CSS currently draws the visible portrait and varied project placeholders. These files are starter assets for when you want file-based image placeholders or replacement imagery.
